# Assistente de Voz Inteligente Multiidiomas

Este é um assistente pessoal inteligente de voz completo, desenvolvido em Python com suporte para múltiplos idiomas.

## 📦 Arquivos do Projeto

- **main.py** - Aplicativo principal com interface interativa
- **config.py** - Configurações centralizadas
- **audio_module.py** - Gravação e armazenamento de áudio
- **speech_recognition_module.py** - Reconhecimento de fala e detecção de idioma
- **ai_module.py** - Processamento inteligente e geração de respostas
- **tts_module.py** - Síntese de fala expressiva
- **setup.py** - Script de instalação automatizado
- **examples.py** - 10 exemplos de uso avançado
- **requirements.txt** - Dependências Python
- **.env.example** - Template de variáveis de ambiente
- **README.md** - Documentação completa

## 🚀 Quick Start

```bash
# 1. Executar setup
python setup.py

# 2. Configurar chaves de API em .env
# (copie de .env.example e configure)

# 3. Executar assistente
python main.py
```
