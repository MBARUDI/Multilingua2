🎓 EXEMPLOS DE USO
══════════════════════════════════════════════════════════════════

Uso Básico:
─────────────────────────────────────────────────────────────────
from ai_module import AIAssistant
from tts_module import TextToSpeech

assistant = AIAssistant()
tts = TextToSpeech()

response = assistant.get_response("Olá, como você está?")
tts.speak(response)

Integração em Projeto Externo:
─────────────────────────────────────────────────────────────────
from audio_module import AudioRecorder
from speech_recognition_module import SpeechRecognizer

recorder = AudioRecorder()
recognizer = SpeechRecognizer()

audio, path = recorder.record_audio()
text, lang = recognizer.transcribe_audio(path)

Multiidiomas:
─────────────────────────────────────────────────────────────────
response_pt = assistant.get_response("Pergunta", language='pt')
response_en = assistant.get_response("Question", language='en')
response_es = assistant.get_response("Pregunta", language='es')

══════════════════════════════════════════════════════════════════
📞 SUPORTE E TROUBLESHOOTING
══════════════════════════════════════════════════════════════════

Problema: Microfone não funciona
Solução:
  1. Verifique conexão física
  2. Teste permissões do SO
  3. Consulte os logs

Problema: Chave de API inválida
Solução:
  1. Verifique chave em .env
  2. Regenere chave se necessário
  3. Teste conexão de rede

Problema: Lentidão
Solução:
  1. Reduza MAX_TOKENS em config.py
  2. Use Groq em vez de OpenAI
  3. Aumente capacidade do computador

Para mais:
  → Veja README.md (seção Troubleshooting)
  → Consulte os logs em logs/assistant.log
